## 4. 확정한 접근

「오늘의 용어」를 사전에서 랜덤으로 뽑지 않는다. **오늘 뉴스에 실제로 등장한 말** 중에서 고르고,
정의는 한국은행·KDI에서 가져온다. 그래야 시의성과 정확성을 동시에 잡는다.

```
RSS 7개 오늘 헤드라인 수집
  -> 헤드라인 형태소에서 용어 후보 추출
  -> 700선/KDI 사전에 실린 것만 남김 (= 설명할 가치 있고 정의 근거도 있음)
  -> 점수화: 오늘 언급 빈도 x 최근 30일 미발행 x 사전 수록
  -> 정확히 1개 확정
```

사전에 없는 신조어는 그날 후보에서 뺀다. 근거 없는 설명을 내보내지 않기 위해서다.
