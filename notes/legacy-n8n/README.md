# 레거시 n8n 워크플로 (복원본)

2026-08 발굴. **n8n은 더 이상 쓰지 않는다** — 설계 참고용 아카이브다.
원본은 `~/Downloads/optimized_news_*.json` (일부 파일 손상 상태).

## 왜 남겨두나

현재 `daily_auto.py` 파이프라인에 **없는 것**이 여기 있다:

1. **이력 DB** — 수집한 뉴스를 누적 저장하고 발송 여부를 표시. 지금은 `output/news/*.json` 파일만 떨어뜨려 '전일 대비' 계산이 불가능했다. → `tools/signal_scan.py`의 SQLite가 이 역할을 이어받음.
2. **Threads 자동발행** — `graph.threads.net/v1.0/{id}/threads` → `threads_publish` → `reply_to_id`로 댓글까지. 인스타 릴스 도달이 막힌 상황에서 외부 유입 경로로 가치가 있다.
3. **장르 균형 프롬프트** — AI 선별 기준에 '음악·미술·연극·영화 균형'이 명시돼 있다. 현재 큐레이션은 미술에 편중돼 있음.
